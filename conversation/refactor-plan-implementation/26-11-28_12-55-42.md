## Trả lời

Task 6.1 xong, nằm trên nhánh `refactor/6.1-shared`. Nhánh này tách từ `refactor/integration-trial`, vì plan yêu cầu Phase 1 và Phase 3 đã có. Chưa push.

**Thư mục `shared/` mới ở gốc repo** (ESM thuần, không dependency, không dùng DOM/Node API; có `shared/package.json` với `"type": "module"` để Node không coi file là CommonJS):

- **`ink-kinds.js`**: `SHAPE_KINDS`, `SHAPE_CLOSED`, `VERTEX_NUMBERS`.
  - Client `lib/shape.js` re-export lại, nên mọi import cũ vẫn chạy.
  - Server `realtime/sanitize-ink.js` dựng `LIVE_INK_KINDS`/`LIVE_INK_FILLABLE_KINDS`/`LIVE_INK_VERTEX_NUMBERS` từ đây, thay cho bản chép tay. Các comment "phải sửa cả hai chỗ" đã xoá.
- **`board-fields.js`**: chuyển từ `server/board-fields.js`; file cũ giờ chỉ re-export.
- **`game-design-limits.js`**: các `GAME_DESIGN_*_LIMITS`, `RELATION_IDS`, và 5 danh sách trạng thái (review, post-launch, A/B, live-ops, handoff).
  - Server validation import từ đây.
  - Client thay các số cắt tay (`slice(0, 20)`…) và các danh sách chép tay bằng hằng số dùng chung.
  - **Mọi số được thay đều bằng đúng trần của server**, nên không đổi hành vi.
  - Hai chỗ có dạng logic khác (mức blocker của delivery, kiểu curve) tôi để nguyên.
- **Vite:** `client/vite.config.js` và `smoke.vite.config.js` thêm `server.fs.allow: [".."]`.

**Test mới**

- Id của `RELATION_OPTIONS` (nhãn phía client) phải khớp `RELATION_IDS` dùng chung.
- `shape.js` re-export đúng các bảng của `shared/`.
- Ba tập `LIVE_INK_*` phía server giữ đúng nội dung như bản chép tay cũ.

**Kiểm tra**

- `npm run verify` pass: client 799 test, build, đủ 5 kịch bản smoke, server 211 test.
- **Thử lệnh của `render.yaml`** trên một bản xuất sạch từ commit (`git archive`):
  - `shared/` có trong cây đã commit;
  - `npm run build` của client chạy được;
  - `npm start` của server nạp đủ module (kể cả `shared/`) rồi dừng đúng ở bước báo thiếu `MONGODB_URI`, vì bản xuất không có `.env`.
- **Chưa chạy `npm install`** trong lần thử này (tôi dùng node_modules sẵn có), để tránh tải mạng và làm đổi lockfile. Phần cài đặt trên Render không phụ thuộc thay đổi này.

**Cần biết**
