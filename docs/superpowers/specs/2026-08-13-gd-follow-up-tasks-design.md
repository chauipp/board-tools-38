# Follow-up Tasks — Design

> Plan: [../plans/2026-08-13-gd-follow-up-tasks.md](../plans/2026-08-13-gd-follow-up-tasks.md)

Mỗi card GD có danh sách follow-up tối đa 20 việc: nội dung, owner, deadline, status `open/done` và reference card. Việc nằm trong dock, badge tiến độ hiện trên card, Markdown xuất danh sách checkbox. Không tạo hệ task/project riêng ngoài board.
