# Lingui i18n Anh/Việt — Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người dùng bấm một nút để chuyển toàn bộ chữ giao diện của app `game-tools` giữa tiếng Việt và tiếng Anh.

**Architecture:** Lingui v6 với macro babel, chuỗi gốc tiếng Việt viết thẳng trong JSX. Một module `lib/i18n.js` sở hữu toàn bộ trạng thái ngôn ngữ và `localStorage`; một component `LocaleToggle` chỉ vẽ nút; `I18nProvider` ở `main.jsx` lo re-render khi đổi ngữ. Ba chỗ đang giữ câu chữ trong React state hoặc ném câu chữ từ tầng API phải đổi sang giữ **dữ liệu**, câu chữ dựng lúc render.

**Tech Stack:** React 18, Vite 5, `@lingui/core` + `@lingui/react` v6.5.0, `@lingui/cli` + `@lingui/vite-plugin` + `@lingui/babel-plugin-lingui-macro` v6.5.0.

**Spec:** `docs/superpowers/specs/2026-07-24-lingui-i18n-design.md`

- [ ] **Step 5: Tạo `src/lib/i18n.js`**

Tạo `game-tools/client/src/lib/i18n.js`. Chú ý `i18n.activate()` được gọi ngay lúc nạp module, trước khi React render, nên không có cảnh nháy chữ sai ngữ:

```js
import { i18n } from "@lingui/core";
import { messages as viMessages } from "../locales/vi/messages.po";
import { messages as enMessages } from "../locales/en/messages.po";

export const LOCALES = ["vi", "en"];
const STORAGE_KEY = "locale-pref";

i18n.load({ vi: viMessages, en: enMessages });

function savedLocale() {
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (LOCALES.indexOf(saved) !== -1) return saved;
  } catch (e) {}
  return "vi";
}

export function activateLocale(next) {
  if (LOCALES.indexOf(next) === -1) return;
  i18n.activate(next);
  try { localStorage.setItem(STORAGE_KEY, next); } catch (e) {}
}

i18n.activate(savedLocale());

export { i18n };
```

- [ ] **Step 1: Viết lại `src/lib/api.js`**

Thay toàn bộ nội dung:

```js
function apiError(code) {
  const err = new Error(code);
  err.code = code;
  return err;
}

export async function getIdeas() {
  const res = await fetch("/api/ideas");
  if (!res.ok) throw apiError("IDEAS_LOAD_FAILED");
  return res.json();
}

export async function saveIdeas(state) {
  const res = await fetch("/api/ideas", {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(state)
  });
  if (!res.ok) throw apiError("IDEAS_SAVE_FAILED");
  return res.json();
}

export async function getCalculator() {
  const res = await fetch("/api/calculator");
  if (!res.ok) throw apiError("CALC_LOAD_FAILED");
  return res.json();
}

export async function saveCalculator(state) {
  const res = await fetch("/api/calculator", {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(state)
  });
  if (!res.ok) throw apiError("CALC_SAVE_FAILED");
  return res.json();
}
```

  function runDuel() {
    if (!canSimulate) {
      setDuelResult({ kind: "cannotSimulate" });
      return;
    }
    if (dmgToB === 0 && dmgToA === 0) {
      setDuelResult({ kind: "stalemate" });
      return;
    }
    let hpA = hp.a, hpB = hp.b, rounds = 0;
    while (hpA > 0 && hpB > 0 && rounds < 500) {
      hpB -= dmgToB;
      hpA -= dmgToA;
      rounds++;
    }
    if (hpA <= 0 && hpB <= 0) setDuelResult({ kind: "draw", rounds });
    else if (hpB <= 0) setDuelResult({ kind: "aWins", rounds, hp: Math.max(0, Math.round(hpA)) });
    else if (hpA <= 0) setDuelResult({ kind: "bWins", rounds, hp: Math.max(0, Math.round(hpB)) });
    else setDuelResult({ kind: "timeout", rounds });
  }
